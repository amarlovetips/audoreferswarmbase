# opBNB AutoTX & Referral Automation Web App

A powerful client-side Web3 automation web app built for the **opBNB Chain (Chain ID 204)**.

## 🌟 Features
- **MetaMask Style 12-Word Seed Phrase (HD Wallet)** generator & restorer using `m/44'/60'/0'/0/i`.
- **opBNB Smart Account** proxy address derivation.
- **Swarmbase Referral Registration** auto-caller with fallback caller strategy.
- **Range-Based Wallet Task Execution** with customizable delay (30s default).
- **Auto-Sweep / Fund Passing**: Cascading max BNB balance passing to the next wallet with a 3x gas fee safety reserve.
- **HTML5 Web Worker Engine**: Execution continues 100% uninterrupted even in background browser tabs or minimized windows.
- **Manual Transfer & Withdraw Modal** with MAX auto-fill.
- **Live 5-second Auto Balance Polling** & opBNBScan Direct Links.

## 🚀 Live Hosting / Deployment

### Deploy on Vercel
1. Push this code to your GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
3. Import your GitHub repository.
4. Click **Deploy**! No build command required.

### Deploy on GitHub Pages
1. Push this code to a GitHub repository.
2. Go to repository **Settings** -> **Pages**.
3. Under **Build and deployment**, select `main` branch and `/ (root)`.
4. Click **Save**. Your site will be live in 1 minute!
